# SeaSoon 1.5

Промпт-режим для DeepSeek: короткие ответы без воды, пятнадцать проверок кода в режиме размышления и разбор скриптов «компилятором» по команде `/com`.

**Сайт:** https://mgtoon.github.io/seasoon/

## Что внутри

| Файл | Назначение |
|---|---|
| `SEASOON.md` | ядро: активация, стиль, режим размышления, `/com`, антислоп |
| `skills/15-checks.md` | пятнадцать проверок, каждая отдельно |
| `skills/compiler.md` | протокол `/com`: формат отчёта и ограничения |
| `skills/anti-slop.md` | замены для кода, интерфейса и текста |
| `seasoon.txt` | всё перечисленное одним файлом |

## Быстрый старт

1. Скопируй `SEASOON.md` (или `seasoon.txt` целиком) и вставь первым сообщением в DeepSeek.
2. Напиши «активируй SeaSoon».
3. Ответ должен быть ровно один: `SeaSoon!` Если модель начала перечислять возможности — промпт не применился.

Дальше включай режим размышления для кода: там работают пятнадцать проверок. Для коротких вопросов хватит обычного режима.

## Команды

| Команда | Что делает |
|---|---|
| `/com` в сообщении | включает протокол компилятора: отчёт по строкам, затем исправленный код |
| «активируй SeaSoon» | включает режим, ответ одной строкой |
| обычный запрос | ответ по делу, без вступлений и заключений |

## Чего режим не делает

- Не запускает код. `/com` — статический разбор, а не исполнение: модель не видит значений в рантайме и обязана писать «разбора прошёл, запуска не было».
- Не заменяет тесты и линтеры.
- Не гарантирует «4–10 минут»: это ориентир глубины, а не таймер. Быстрый ответ означает, что проверки пройдены поверхностно.

## Как проверить, что режим включён

1. Попроси: «активируй SeaSoon». Ответ — только `SeaSoon!`.
2. Попроси: «напиши функцию суммы по CSV с `/com`». В ответе должен быть блок `COMPILE REPORT` с номерами строк, а не общие слова.
3. Попроси объяснить выбор решения. Не должно быть фраз «Отличный вопрос», «Важно отметить», «Надеюсь, это поможет».

# SeaSoon 1.5 (EN)

A prompt mode for DeepSeek: short answers without filler, fifteen code checks in thinking mode, and a `/com` compiler-style review.

**Site:** https://mgtoon.github.io/seasoon/

Copy `SEASOON.md` (or the whole `seasoon.txt`) as the first message, then write "activate SeaSoon". The expected answer is exactly `SeaSoon!` — nothing else.

`/com` triggers a static review report: line, error class, severity, fix. The model does not execute code and must say so.
