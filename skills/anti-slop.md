# Антислоп

## Код

| Плохо | Почему | Хорошо |
|---|---|---|
| `if (ok == true) return true; else return false;` | ветвление ради ветвления | `return ok;` |
| `try { ... } catch (e) {}` | ошибка проглочена | ловить конкретное исключение и обрабатывать |
| `class UserManagerFactoryProvider` | три суффикса на одну таблицу | `class UserRepository` |
| `const data = await fetch(...)` | имя не говорит ничего | `const response = await fetch(...)` |
| пакет `is-odd` ради проверки на чётность | зависимость ради строки | `value % 2 === 0` |
| «готово» с тремя `TODO` внутри | работа не сделана | либо сделать, либо назвать незавершённым |
| `// инициализируем переменную` | объясняет очевидное | комментарий про причину решения |
| фейковые данные в рабочем коде | пользователь примет за правду | явный `mock` в имени или пустое состояние |
| функция на 200 строк | нечитаемо | разбить по смыслу |
| магическое `86400` | непонятно | `SECONDS_PER_DAY` |

## Интерфейс

| Плохо | Почему | Хорошо |
|---|---|---|
| градиент `#6366f1 → #a855f7` | дефолт генераций | один акцентный цвет |
| стеклянные панели с blur | падает контраст | плотный фон и граница 1px |
| три карточки Features с иконками в кружках | нечего сказать о продукте | список из 2–5 пунктов текстом |
| тень у каждой карточки | нет понятия слоя | тень только у всплывающего |
| эмодзи вместо иконок | разный рендер | SVG `<path>`, один `stroke-width` |
| `[название продукта]` в вёрстке | это не макет, а отказ от работы | рабочий текст или вопрос |
| всё по центру | нет иерархии | сетка и выравнивание по смыслу |
| радиус 24px у всего | блоки выглядят одинаково | 4–8px, у больших поверхностей 12 |
| «Trusted by 10 000+» | вымышленная социальная доказанность | проверяемые цифры или ничего |
| `href="#"` | ссылка-пустышка | реальный адрес или кнопка |

## Ответ

Не писать:

- «Отличный вопрос»
- «Давайте разберёмся»
- «Важно отметить»
- «В современном мире»
- «Это не просто X, это Y»
- «Надеюсь, это поможет»
- «Дайте знать, если нужно что-то ещё»

## Проверка перед выдачей

1. Убрать все прилагательные без числа или факта. Смысл сохранился — значит, это был мусор.
2. Найти все места, где написано «готово». Проверить каждое запуском или убрать слово.
3. Найти все `TODO` и `catch`: либо исправить, либо назвать в отчёте.
4. Прочитать ответ вслух. Если звучит как реклама — переписать.
