# Пятнадцать проверок

Каждая проверка выполняется отдельно и заканчивается правкой или строкой отчёта. «Прошёл всё» одним взглядом не считается.

## 01. Синтаксис

Скобки, кавычки, отступы, точки с запятой там, где язык их требует, закрытые блоки. Опечатки в ключевых словах (`functon`, `retrun`, `elsif`).

## 02. Типы

Приведение типов, сравнение разных типов, деление целых, `undefined`/`None`, неявные преобразования. В статически типизированных языках — совпадение сигнатур.

## 03. Области видимости

Переменная, объявленная в цикле и используемая после; затенение внешней переменной; `this`/`self` в замыкании; глобальные переменные.

## 04. Неинициализированные значения

Использование переменной до присваивания, `null` после неудачного поиска, пустая строка вместо числа, отсутствующий ключ словаря.

## 05. Границы

Индексы с нуля и с единицы, пустой массив, последний элемент, срез за пределами, длина строки в байтах против символов.

## 06. Арифметика

Деление на ноль, переполнение, точность чисел с плавающей точкой (`0.1 + 0.2`), округление денег, отрицательные значения там, где ожидались положительные.

## 07. Ветки и возвраты

Функция без `return` на одной из веток, недостижимый код после `return`, `switch` без `default`, цикл без выхода.

## 08. Ошибки

Пустые `catch`, проглоченные исключения, ловля слишком широкого класса ошибок, отсутствие проброса контекста, сообщения вида «Ошибка».

## 09. Ресурсы

Файлы, сокеты, процессы, соединения с базой: закрываются ли, есть ли `with`/`try-with-resources`/`defer`. Утечка при исключении.

## 10. Параллельность

Гонки при общем состоянии, блокировки без освобождения, повторный вход, `async` без `await`, забытый `await` в цикле, порядок завершения задач.

## 11. Ввод-вывод

Кодировка (UTF-8 явно), пути с пробелами и кириллицей, права на запись, отсутствующий файл, частично прочитанный ответ сети, таймаут.

## 12. Безопасность

Секреты в коде, SQL-конкатенация, `eval`, небезопасная десериализация, путь из пользовательского ввода, отключённая проверка сертификата, `shell=True` с внешними данными.

## 13. Производительность

Квадратичные циклы на больших данных, запрос в цикле, лишние копии коллекций, чтение файла целиком там, где нужен поток.

## 14. Зависимости

Версии зафиксированы, пакет существует, лицензия подходит, нет пакета ради одной функции, нет пакета из непроверенного источника.

## 15. Читаемость

Имена по смыслу, отсутствие дублирования, мёртвый код удалён, магические числа названы, комментарии объясняют причину. Финальный проход «как ревьюер в чужом репозитории».

## Отчёт

```
SEASOON CHECK 15/15
01 синтаксис — ок
02 типы — ок
03 области — исправлено: переменная вынесена из цикла
...
15 читаемость — ок
Не проверено: 10, параллельности в коде нет
```
